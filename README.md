# VR Workshop

Atelier 3D minimaliste conçu pour navigateur desktop, mobile et Meta Quest 3.

Ouvrir `index.html` via HTTPS (GitHub Pages). Créez des cubes, sphères et cylindres, sélectionnez et déplacez les objets dans la scène, réglez leur taille et leur couleur, puis enregistrez ou exportez la scène. La sauvegarde automatique reste dans le stockage local du navigateur.

Les boutons VR/MR détectent les capacités WebXR du navigateur. La VR et le passthrough MR nécessitent un navigateur et un appareil compatibles; GitHub Pages fournit HTTPS.
